## Unit 1 — Unit 1

**Scope:** Teaches integration with the quantitative stack: the complementarity logic — ethnography explains what computational methods detect, computational methods show whether ethnographic readings generalize; sequential designs — netnography-first (qualitative exploration generating hypotheses and codebooks for NLP/network analysis) versus computation-first (anomaly detection in metrics triggering ethnographic investigation); parallel designs — simultaneous fieldwork and data science on the same phenomenon with convergent validation; the codebook bridge — turning ethnographic themes into annotation schemes for computational text analysis (course 1 integration), with inter-rater reliability and drift checks; embedding network analysis — using community-structure findings (course 2) to select netnographic sites and key members, and using ethnographic reading to interpret detected communities; validating sentiment at ground level — checking algorithmic sentiment against ethnographically known context (irony, in-group meaning); scale tension management — depth-versus-breadth trade-offs, and sampling computational corpora for ethnographic deep-reads; mixed-methods quality criteria — integration happening at design, analysis, and interpretation levels, not just reporting side-by-side findings; toolchain practice — connecting capture, coding software, and analysis pipelines with shared data governance; team models — ethnographer-analyst collaboration patterns and translation frictions; the mixed-methods report — weaving thick description with quantitative patterns into single narratives; and the trend-intelligence system — netnography as the meaning layer in a full pipeline (detection, measurement, interpretation, forecast).
