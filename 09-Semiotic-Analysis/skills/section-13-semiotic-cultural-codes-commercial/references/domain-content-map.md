## Unit 1 — Unit 1

**Scope:** Covers professional research practice: commercial semiotics defined — the applied field using sign analysis for brand positioning, innovation, and communication strategy (the Semionaut-lineage agencies, cultural-code mapping consultancies); cultural codes — the deep conventionalized meaning structures of a culture (rapaille-lineage code work presented critically, the more defensible structural approach: codes as documented, historically variable meaning conventions); code mapping method — building the meaning map of a category (the coffee category's codes: fuel, ritual, craft, comfort, status) from corpus analysis, revealing positioning whitespace; the research workflow — brief translation (business question to semiotic question), corpus construction (multi-channel, diachronic sampling), analysis (denotation through myth), synthesis (meaning maps, code hierarchies), and translation back to strategy; triangulation with other methods — combining semiotics with quantitative text analysis (coding schemes from semiotic analysis), ethnography (course 7 integration: observed practice grounding sign readings), and surveys (audience-decoding validation); semiotic segments — audience mapping by code competence and preference rather than demographics; diachronic code analysis — tracking a code's historical shifts as trend evidence (how 'health' coding moved from absence-of-illness to optimization to holistic); the deliverable formats — meaning maps, semiotic territories, code books, and implication statements with the strategy bridge made explicit; quality standards — interpretive discipline (evidence-grounded readings), context documentation, and the humility clause (analyst readings as hypotheses for audience testing); ethics in commercial semiotics — representation analysis without stereotyping, cultural respect in code mining; and practice — running a category code-mapping project from brief through meaning map to strategic implications.
