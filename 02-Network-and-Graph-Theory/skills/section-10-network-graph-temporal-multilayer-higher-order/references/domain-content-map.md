## Absorbed capabilities this module must produce
1. Analyze temporal networks with time-respecting paths and aggregation trade-offs, quantify interaction burstiness and its diffusion consequences.
2. Model cross-platform spread as multilayer networks.
3. Apply higher-order interaction thinking where group dynamics matter, and judge when temporal and multilayer complexity is analytically necessary.

## Unit 1 — Unit 1

**Scope:** Teaches structure beyond static snapshots: temporal networks — time-stamped contacts, temporal paths and reachability (why static analysis overestimates what can spread), time-respecting ordering, and the aggregation trade-off; burstiness of human communication — inter-event-time distributions and the burstiness parameter, with consequences for diffusion timing; temporal centrality and community evolution methods; multilayer and multiplex networks — the same actors across platforms, interlayer coupling, and cross-platform meme migration (the Reddit-to-TikTok-to-Instagram pipeline as the working example) analyzed in multilayer terms; higher-order interactions — hypergraphs and simplicial complexes capturing group interactions irreducible to pairs, and higher-order contagion results (simplicial thresholds changing outbreak dynamics); dynamic graph representations — event lists versus snapshot sequences; data realities — observation windows, API history limits, and censoring; tooling — temporal network libraries and multilayer frameworks at working level; and the judgment call — when temporal and multilayer complexity changes conclusions versus when aggregated static analysis suffices.
