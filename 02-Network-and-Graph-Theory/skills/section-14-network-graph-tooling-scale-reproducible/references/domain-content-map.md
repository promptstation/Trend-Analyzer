## Unit 1 — Unit 1

**Scope:** Builds professional craft: the Python/R network stack in depth — NetworkX for prototyping and algorithm richness with memory limits, igraph for performance, graph-tool for heavy computation, cdlib for community methods — and selection criteria; large-graph handling — sparse matrices, graph databases and query languages, streaming updates, and graph sampling methods (snowball, forest-fire) with estimator bias; visualization practice — Gephi workflows, layout algorithms and their distortions, network figures that communicate findings versus decorate, and interactive tooling (pyvis, Cytoscape.js); performance patterns — vectorization, edge-list discipline, parallelized community detection; reproducibility — seeds, versioned graph artifacts, documented pipelines, and small-known-graph unit tests for network code; integration with the wider trend stack — NLP entities feeding co-mention graphs, cascade data feeding diffusion models, network features feeding forecasts; collaboration artifacts — sharing graphs, notebooks, and figure standards; and the cost discipline of not building graph infrastructure when a dataframe suffices.
